# v0.5.2 Spring Boot REST 校验设计

## 目标

新增 `exercises/spring-boot-rest-validation` 练习模块和中文课程章节，让学生在 Spring Boot 配置之后掌握请求 DTO 校验、`@Valid`、统一 400 错误响应和轻量 MVC 测试。

## 范围

- `CreateCourseRequest`：使用 Jakarta Bean Validation 描述标题、课时数和级别规则。
- `CourseController`：创建接口启用 `@Valid`，保留列表、详情和 404 行为。
- `ApiExceptionHandler`：把校验异常转换为稳定 JSON 响应。
- starter/solution 双模块：starter 可编译且测试默认禁用，solution 完整实现。
- README、中文课程、路线图、首页和 VitePress 导航更新。

## 验证

- `mvn -B clean verify`
- `npm run check:links --prefix website`
- `npm run docs:build --prefix website`
