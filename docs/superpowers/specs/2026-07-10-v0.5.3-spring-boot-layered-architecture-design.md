# v0.5.3 Spring Boot 分层架构设计

## 目标

新增 `exercises/spring-boot-layered-architecture` 练习模块和中文课程章节，让学生在 REST 校验之后掌握 Controller、Service、Repository、DTO 和实体的职责边界。

## 范围

- Controller：处理 HTTP 边界和响应码。
- Service：组织业务流程、业务规则和 `@Transactional` 边界。
- Repository：通过接口隔离数据访问，使用内存实现模拟持久化。
- DTO/Entity：区分请求、响应和内部业务对象。
- starter/solution 双模块、README、中文课程、路线图、首页和导航更新。

## 验证

- `mvn -B clean verify`
- `npm run check:links --prefix website`
- `npm run docs:build --prefix website`
